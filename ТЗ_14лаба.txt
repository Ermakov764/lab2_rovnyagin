LAB14 
Подключить свой узел к кластеру kubernetes (k3s).
Ознакомиться с текущими настройками и выполнить настройки на своем узле для включения его в состав общего кластера (Разделы 5 и 6) https://bitbucket.org/zil-courses/hl-module2/src/main/K3S-SETUP.md?at=main 

Разработать YAML-манифесты развертывания приложения (основной микросервис и дополнительный) в k3s. Манифесты должны включать: Deployment’ы, Service для обеспечения внешнего доступа (тип NodePort) для проверки SwaggerUI, Service для обеспечения внутреннего доступа (вызов основного сервиса сервисом статистики), ConfigMap для инициализации ENV-параметров приложений, Secret для инициализации пароля доступа в БД, Secret для инициализации доступа в DockerHub (создается вручную, в Git разместить файл-шаблон). Указать явно (создать) namespace по имени своего варианта. Задать ресурсы по 1 ядру на каждый сервис, память до 1GB (Guaranteed). Указать DB_HOST как 10.60.3.9
Заменить KAFKA_HOSTS на 10.60.3.12,10.60.3.13  (прописываем IP, так как CoreDNS K3S не сконфигурирован под резолвинг hlXX.zil, либо использовать hostAliases https://kubernetes.io/docs/tasks/network/customize-hosts-file-for-pods) 

Продемонстрировать успешное развертывание манифестов через kubectl apply -f, 
С помощью kubectl port-forward service/… пробросить порт на локальную машину или виртуалку и продемонстрировать работу SwaggerUI, также продемонстрировать успешный доступ к SwaggerUI одного и другого микросервисов через NodePort’ы.
